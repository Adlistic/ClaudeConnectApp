# ClaudeConnect

Downloads for **ClaudeConnect** — a live desktop viewer for your Claude Code sessions.

## Download

The latest Windows installer / binary is on the [Releases page](https://github.com/Adlistic/ClaudeConnectApp/releases/latest).

## What is ClaudeConnect?

ClaudeConnect watches the JSONL transcript files Claude Code writes and streams every prompt, message, tool call, plan, and thinking block to a native desktop app — useful as a second-monitor mirror, for streaming, or for keeping a visual record of your sessions.
